(ou atualize o path em `src/config/sellerflow-media.ts`).

| `screenshots/products-fechamento-v1.png` | Showcase Produtos do Fechamento |
| `screenshots/fechamento-resultado-v1.png` | Showcase Fechamentos (Resultado) |
| `screenshots/home-v1.png` | Showcase Home |
| `video/demo-poster.png` | Poster do vídeo |
